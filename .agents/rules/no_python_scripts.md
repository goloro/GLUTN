# Restricciones de Modificación de Archivos

- **NUNCA** utilices scripts temporales de Python (.py) ni ningún otro lenguaje de scripting para buscar, reemplazar, limpiar o editar archivos en este proyecto.
- **SIEMPRE** utiliza las herramientas nativas del sistema (eplace_file_content o write_to_file) para modificar el código de forma directa y sin dejar rastro de archivos basura en el entorno del usuario.
