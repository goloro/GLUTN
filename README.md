# GLUTN 🌾🚫

GLUTN es una aplicación web *mobile-first* diseñada para ayudar a las personas con celiaquía o intolerancia al gluten a identificar si un producto es seguro para su consumo de forma rápida, sencilla y gratuita.

## ✨ Características Principales

*   **Escáner de Códigos de Barras (EAN)**: Utiliza la cámara del dispositivo para escanear el código de barras de cualquier producto y consulta instantáneamente bases de datos abiertas para verificar si está certificado como "Sin Gluten".
*   **Análisis Inteligente de Ingredientes (IA)**: ¿El producto no está en la base de datos o es de importación? Sácale una foto a la lista de ingredientes. GLUTN utiliza un motor de Inteligencia Artificial para leer, traducir y analizar la composición en segundos, detectando alérgenos o ingredientes sospechosos.
*   **Soporte Multi-Idioma**: La aplicación detecta automáticamente el idioma de tu dispositivo y se adapta. Traduce instantáneamente cualquier etiqueta extranjera a tu idioma materno. Disponible en Español 🇪🇸, Inglés 🇬🇧, Francés 🇫🇷, Alemán 🇩🇪 e Italiano 🇮🇹.
*   **Historial Local**: Guarda un registro de tus escaneos recientes directamente en la memoria de tu teléfono para que puedas consultarlos sin conexión más tarde. ¡100% privado!

## ⚠️ Disclaimer

GLUTN utiliza IA y bases de datos abiertas. La información proporcionada es orientativa y no infalible. Recomendamos **siempre** revisar la etiqueta física del producto, especialmente en casos de celiaquía severa o alergias cruzadas.
